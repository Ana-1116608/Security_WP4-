# Progressive Web App voor afstudeeropdrachten

Een PWA, of [Progressive Web App](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps) is een manier om een app-achtige beleving te bouwen met webtechnologie. Zo tover je een website om in iets dat je vanuit je browser, zonder tussenkomst van een App Store, kan installeren op je telefoon of computer.

Doel van de opdracht is een PWA te bouwen zodat studenten kunnen kiezen uit afstudeerprojecten bij bedrijven. De bron van deze data is de [API](./api) die in deze repo te vinden is. Studenten moeten vanuit deze data de volgende dingen kunnen doen:
* de applicatie op hun homescreen van hun telefoon zetten,
* projecten bekijken,
* projecten delen met anderen (via een link),
* op projecten reageren (email-applicatie openen met nieuw emailvenster met vooringevuld email-adres),
* projecten opslaan om er later (offline) naar te kijken,
* de applicatie offline gebruiken.
